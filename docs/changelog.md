# v0.0.8 alpha

- Render clickable web links and Markdown in messages. Edit formatted Markdown
  directly in the composer, with formatting shortcuts, semantic undo and safer
  draft recovery during input-method composition.
- Queue eligible offline messages and actions, preserve durable outgoing work
  across restarts, and distinguish waiting messages from server acceptance.
  Allow pasting into offline drafts.
- Group image and video previews in a shared media dialog. Improve original-file
  loading, gallery navigation, video seeking and replay.
- Show reply previews immediately and clear the quote after sending. Improve pin
  navigation and animations, and move forwarding into a dedicated dialog.
- Simplify conversation settings and member lists. Add native CSV file loading,
  load bots when their tab opens, and remove group-only controls from direct chats.
- Reuse cached user avatars across chat surfaces. Retain eligible room metadata
  for offline reading and refresh confirmed settings quietly in the background.
- Replace routine busy notices with pending controls and initial-load skeletons.
  Improve dialog transitions, context-menu spacing, reaction controls and call
  history status icons.

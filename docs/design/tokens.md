# Design tokens

**Target specification.** Palette values below describe the preferred blue direction and the sage comparison. Semantic roles and accessibility requirements take precedence over literal colors and small text in retained HTML/PNG sketches. Units are logical points for native UI; CSS pixels are only the mockup measurement reference.

## Native material and elevation

Material sits on the existing palette; it does not replace the blue or sage
canvas, content, chrome, semantic, or call-stage colors. The runtime's light
blue canvas is `#EEF4FD`, its content surface is `#FFFFFF`, and the dark blue
canvas and content are `#172131` and `#1C2633`. The corresponding sage canvas
and content are `#E9E7BF` and `#FFFFFF` in light mode, `#1A211F` and
`#1F2724` in dark mode. Brand gradients use only the existing palette stops.

The only texture is the project grain: a 128 × 128 pixel tile at 2.35% opacity,
generated by `tools/ui/generate-materials.py`. It covers the window canvas and the
sidebar. The white chat surface and dialogs stay smooth and use gray steps (the
`subtle` tone for dialog headers and footers) instead. There is no linear pattern: the earlier dot grid was removed because its
tile boundaries read as dashed vertical lines. Tile edges are snapped to whole device
pixels in absolute window coordinates, so neighboring tiles never overlap or leave
a seam at any display scale. The prepared image carries a one-texel margin of its own
wrapped neighbors, hidden behind a content mask; without it the sampler's edge
clamping drew every tile boundary as a dashed line. Retained bounded texture views reuse their paint when
geometry and clipping stay unchanged; no animation or per-frame noise generation
is used. Input fields use opaque backgrounds.

Floating surfaces use an 8 pt backdrop blur (wide enough to dissolve text behind a
dialog into a soft tone; 4 pt left legible ghost lines) behind a palette-colored tint
(87% light, 88% dark), a hairline and a one-point light inner highlight. Text
tiers retain the required contrast even over an extreme backdrop. The
renderer paints the original opaque surface when backdrop blur is unavailable.
Native secondary text uses `#485B75` on light blue and `#515D53` on light sage
so it remains readable when the glass samples a dark background.
Reduce Transparency also uses opaque surfaces and disables decorative textures
and glass. Unknown platform preference is treated as Reduce Transparency. The
Linux UI-scenario-only `TALK_UI_MATERIAL_PREVIEW=1` override exists for visual
and performance evidence; it never changes normal application behavior.

| Elevation | Near shadow | Far shadow |
| --- | --- | --- |
| Card | 0 1 2, 7% light / 22% dark | 0 8 24, 10% light / 40% dark |
| Raised control | Same near shadow × 0.7 | 0 3 8, same far alpha × 0.7 |
| Popover | Same near shadow × 1.3 | 0 8 24, same far alpha × 1.3 |
| Dialog | Same near shadow × 1.6 | 0 16 40, same far alpha × 1.6 |

Light shadows use the existing cool text hue `#26354B`; dark shadows use black.
Shadows and highlights are decorative and do not carry state or focus meaning.

| Semantic role | Foreground / light background | Required accompanying cue |
| --- | --- | --- |
| Information / selected label | `#315E98` / `#EAF1FB` | Action label, selected state, or information icon |
| Available / success | `#286343` / `#EDF7F0` | “Verfügbar” or a success message |
| Waiting / warning | `#795300` / `#FFF4D6` | “Verbinde …” or “Offline” in the title bar, or the specific warning |
| Error / destructive action | `#9E3E32` / `#FFF0EC` | Error explanation, “Ablehnen”, “Auflegen”, or “Löschen” |
| Recording | `#9E3E32` / `#FFF0EC` | Recording icon plus “Aufzeichnung läuft”; consent is separate |

The role colors apply in two ways. Text never uses them: a notice's title is
`text.primary`, its detail `text.secondary` and its action `selection` text, all
verified at 4.5:1 on the notice wash. The role color is used for the 16 pt role icon
(3:1) and, at 72% (light) or 55% (dark) opacity of the role background, for the
wash behind the notice.

## Notices and connection status

| Part | Value |
| --- | --- |
| Notice | Rounded 10 pt, wash only, no outline, minimum height 36 pt. Role icon 16 pt, title 13 / 18 pt medium, detail 12 / 18 pt secondary, 12 pt side padding. Wraps: the action drops under the text in a narrow container. |
| Notice action | Text weight 13 pt medium in `selection` text, minimum 28 pt high inside the line. |
| Centered state | 52 pt tile, 26 pt icon, semibold title, secondary detail, at most one action, maximum width 420 pt. |
| Read-only bar | Replaces the composer: 16 pt lock, "Nur Lesezugriff" medium, one muted sentence, hairline above. |
| Status pill | 24 pt high inside a 32 pt control, full radius, warning wash, 7 pt dot, 12 pt medium word, optional "· N" in secondary text. Dot `#B37400` on light themes (3:1 on the wash) and the away-presence amber on dark themes. |
| Status popover | Popover elevation and glass, 300 pt wide, 4 pt below the control. |

Scopes, roles and copy rules are in [Shell navigation and status](shell-navigation-and-status.md).
Message-level states (a failed send, delivery) use the same notice and action styles.

These roles are shared across palettes. Gray indicates unavailable/unknown state with a reason. An unread count combines a number and emphasis; speaker activity combines an outline with a speaking indicator. Do not recolor every status blue or use avatar color as a status.

## Typography and alignment

`D-T01`: Google Sans is the runtime typeface; Manrope belongs to historical sketches. Use the bundled Regular, Medium and Bold weights for body, controls and headings. Use the platform font for system-owned UI and as a fallback. Validate fallback glyphs, emoji and international scripts without clipping. See the [font notice](../../NOTICE.md#google-sans-and-gpui).

| Role / metric | Native target or reference |
| --- | --- |
| Body / message | 14 pt / 22 pt line height, weight 400 |
| Conversation-list title | 13 pt / 18 pt, weight 650 |
| Secondary label / timestamp | 12 pt / 18 pt; do not copy the sketches' 8–10 px labels as a shipping default |
| Screen heading | 20–28 pt / 1.25 line height, weight 700 |
| Spacing scale | 4, 8, 12, 16, 24, 32; related controls share an 8 or 12 pt gap |
| Icon box | 20 × 20 pt; consistent optical centering and stroke weight |
| Standard control | 36 pt high; at least 32 × 32 pt interactive hit area |
| Primary form action | 44–46 pt high; label and icon centered on the same control axis |
| Common radii | 6 pt chips, 8 pt controls, 12 pt menus and cards, 16 pt dialogs and content card; native window corners are system-owned |
| Baseline alignment | Align sender and time on one baseline; body starts at the same x-coordinate; keep avatars in a fixed column |
| Screenshot reference | 1280 × 900 canvas; 1120 × 760 schematic window; 44 px title bar; 278 px sidebar |
| Call reference | 1096 × 704 inner sheet; 274 px chat panel; 64 px header; 90 px control area |

`D-T02`: Resize around content. A narrow window collapses secondary panels before truncating primary actions; a long name can wrap in details. Keep chat and call controls reachable at larger text sizes. The fixed-size mockup is not evidence of a responsive native layout.

## Accessibility targets

| ID | Acceptance target |
| --- | --- |
| **D-A01** | At least 4.5:1 text contrast and 3:1 for essential control/state graphics. Measure actual composited backgrounds, including selected and focus states. |
| **D-A02** | Full keyboard operation, visible unobscured focus, sensible reading/tab order, no keyboard trap, and focus restoration after dialogs. Receiving a call must not accept it through an unrelated keystroke. |
| **D-A03** | Expose names, roles, values, toggle states and selected conversation to VoiceOver. Announce meaningful connection/error changes without reading every timer or audio-meter update. |
| **D-A04** | Text can scale to 200% without loss of primary actions or message content. Honor the macOS contrast/transparency settings and retain status labels in monochrome. |
| **D-A05** | Use short, finite ease-out transitions: 110 ms for hover and switch feedback, 140 ms reveals for dialogs, settings pages, transient feedback and newly appended messages. Closing is immediate. Message entry preserves row geometry and the reader's anchor; only a reader already at the end follows new content after a brief delay. Respect Reduce Motion, including when the system preference is unknown. No flashing ringing effect. Audio cues have visible equivalents. |
| **D-A06** | Controls have at least 32 × 32 pt hit areas; use 44 pt for principal call actions where space permits. Tooltips supplement persistent labels; they are not the only accessible names. |

The contrast, keyboard, focus and scaling targets use [WCAG 2.2](https://www.w3.org/TR/WCAG22/) as measurable design criteria alongside macOS accessibility conventions. This is not a WCAG conformance claim for a native application. Hit-area sizes above are project targets.

**Known design debt:** original screenshots contain small metadata, some muted labels below target contrast, and decorative mock controls. Native focus, dark appearance, text scaling and VoiceOver need implementation and testing. The blue prototype's historical `--muted: #6D7C91` is not the approved small-text token.

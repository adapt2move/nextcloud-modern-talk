# Application sounds

Three fixed sounds are selected by purpose; the user controls banner/sound policy, not a sound library. The operating system delivers notification sounds and retains Focus/Do Not Disturb control. The speaker test plays the incoming ringtone once.

| File | Purpose | Source and terms |
| --- | --- | --- |
| `message-notification.wav` | Messages and non-call notices | Ocean, Guilherme Marçal Silva (2023), CC BY-SA 4.0; format conversion only |
| `call-ringtone.wav` | Incoming call and speaker test | AOSP/New Wave Labs DreamTheme, Apache-2.0; shortened and softened |
| `call-ringback.wav` | Outgoing call waiting | aj_heels, PhoneAlarm01.wav, CC BY 4.0; softened official MP3 preview |
